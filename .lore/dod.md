# Definition of Done

> The specification requires setup-*.sh scripts to hold no SQL of their own, but setup-local-schema.sh still contains inline SQL.

**Strategy: `mechanical`** — The ticket is a fully-specified refactoring to extract inline SQL strings into separate files. Its behaviour is pinned by the existing CI schema comparison test, which ensures the resulting schema remains identical to the Helm hook's output.

The red bar is CI's to show: the `migrations.yml` CI workflow runs `compare-baseline-install.sh`.

## Done when these pass

- [ ] **compare-baseline-install** — The schema generated by setup-local-schema.sh matches the Helm hook's schema.
  `scripts/ci/compare-baseline-install.sh`

## Facets

- [ ] Extract the role creation and `lore` schema creation SQL block from `scripts/infra/setup-local-schema.sh` into a new file, e.g., `scripts/infra/setup-local-roles.sql`.
- [ ] Extract the ownership reconcile SQL block into a new file, e.g., `scripts/infra/setup-local-ownership.sql`.
- [ ] Replace inline SQL blocks in `scripts/infra/setup-local-schema.sh` with commands piping those new files.

## Out of scope

- Altering the resulting database schema structure or changing the migration runner logic.
