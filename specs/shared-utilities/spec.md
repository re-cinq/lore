# Feature Specification: Shared Utilities

| Field   | Value                |
| ------- | -------------------- |
| Feature | Shared Utilities     |
| Status  | In Progress          |
| Owner   | Platform Engineering |

Shared Utilities documents the behavioural contracts of the small cross-cutting helpers in `libs/shared` — retry/backoff, bounded concurrency, path/text classification, the `enforce` guard, the LLM provider abstraction, embeddings, and the Dgraph client — so their unit tests trace to a statement without scattering the contracts across feature specs.

## Problem Statement

`libs/shared` carries small, cross-cutting helpers (retry/backoff, bounded
concurrency, path/text classification, the `enforce` precondition guard, the
LLM provider abstraction, embeddings, the Dgraph client) that many features
depend on but that no single feature spec owns. This spec documents each
helper's behavioural contract so its unit tests trace to a statement, keeping
the traceability graph complete without scattering the contracts across
feature specs.

- **FR — backoff:** `withBackoff` returns the first success without sleeping, otherwise retries across the configured delays awaiting each in order, and rethrows the last error after all `delaysMs.length + 1` attempts are exhausted. An optional `retryOn` predicate gates which errors retry: a rejected error rethrows immediately with no sleep, an accepted one keeps the full schedule, and omitting the predicate retries everything. ([validated by `backoff.test.ts@eff224f3`](libs/shared/src/lib/backoff.test.ts#L14), [`backoff.test.ts@e1627a73`](libs/shared/src/lib/backoff.test.ts#L25), [`backoff.test.ts@ff528059`](libs/shared/src/lib/backoff.test.ts#L43), [`backoff.test.ts@712f4e5c`](libs/shared/src/lib/backoff.test.ts#L60), [`backoff.test.ts@bf41f4c0`](libs/shared/src/lib/backoff.test.ts#L82), [`backoff.test.ts@7a2abe82`](libs/shared/src/lib/backoff.test.ts#L104))

- **FR — backoffDelay:** returns `baseMs * 2^attempts` capped at `maxMs`, flooring a negative attempt count at the base delay, so every exponential schedule in the platform is one function rather than a re-derivation per caller. ([validated by `backoff.test.ts@b0c7d743`](libs/shared/src/lib/backoff.test.ts#L6))

- **FR — runPollLoop:** ticks while `running()` holds, awaits `onOutcome` before the sleep that follows it, and sleeps whatever `delayFor(outcome, idleTicks)` returns — where `idleTicks` counts the consecutive `isIdle` outcomes BEFORE this one, so the first idle tick still sleeps the base delay and only consecutive ones grow it. Omitting `isIdle` makes every outcome non-idle, giving a flat interval; a `running()` that is false from the start runs no tick at all. ([validated by `backoff.acceptance.test.ts@407a304a`](libs/shared/src/lib/backoff.acceptance.test.ts#L5), [`backoff.acceptance.test.ts@d2c3ca00`](libs/shared/src/lib/backoff.acceptance.test.ts#L55), [`backoff.acceptance.test.ts@713a669f`](libs/shared/src/lib/backoff.acceptance.test.ts#L79))

- **FR — pollUntil:** returns the first non-null value `tick` yields without sleeping, and otherwise retries forever, sleeping the `backoffDelay` schedule from `baseDelayMs` up to `maxDelayMs`. ([validated by `backoff.acceptance.test.ts@f4ec0dc2`](libs/shared/src/lib/backoff.acceptance.test.ts#L96))

([validated by `enforce.test.ts@2e8c5f57`](libs/shared/src/lib/enforce.test.ts#L15), [`enforce.test.ts@4c07ce01`](libs/shared/src/lib/enforce.test.ts#L19), [`enforce.test.ts@e86f7766`](libs/shared/src/lib/enforce.test.ts#L25), [`enforce.test.ts@07097205`](libs/shared/src/lib/enforce.test.ts#L31), [`enforce.test.ts@fa3a6cf9`](libs/shared/src/lib/enforce.test.ts#L39), [`enforce.test.ts@473460e3`](libs/shared/src/lib/enforce.test.ts#L55), [`enforce.test.ts@22a2ba64`](libs/shared/src/lib/enforce.test.ts#L64), [`enforce.test.ts@133eaccd`](libs/shared/src/lib/enforce.test.ts#L71), [`enforce.test.ts@87533b51`](libs/shared/src/lib/enforce.test.ts#L79), [`enforce.test.ts@eda1d256`](libs/shared/src/lib/enforce.test.ts#L85))

- **FR — outbound calls carry a deadline:** Every `fetch` in the repo passes a `signal`, so no outbound call can hang forever. A call without one waits as long as the peer keeps the socket open, which inside a single-threaded job loop means the LOOP waits — the failure that froze spec-trace ingestion once and left the Floor's `SERIAL_DEADLINE_MS` guard behind as a scar; that guard bounds the damage without stopping the call from hanging. Fifty-nine sites lacked one, so the invariant is enforced by the `re-lint/require-fetch-timeout` ESLint rule rather than by having swept them: a sweep fixes the sites that exist and the next `fetch` anyone writes is the regression. Any `signal:` satisfies it, whatever produces it — `AbortSignal.timeout(ms)` usually, but a caller-supplied signal is a deliberate decision about who owns the deadline, and demanding the literal form would push callers to re-derive a deadline they were handed. A spread passes, because the signal may be inside one and a rule that guesses in the noisy direction gets disabled rather than obeyed. A request MEANT to stay open — an SSE stream, a log tail — disables the rule on its line with a reason, so the intent sits next to the call instead of being inferred; the run-viz stream instead passes the request's own `signal`, which ends when the client disconnects.
