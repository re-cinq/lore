# Lore Derived Code Graph

At ingest time, for every onboarded repo, derive and write graph edges that today exist only if someone calls `lore_write_episode`:

- Statement 1. After one ingest, `lore_query_graph({entity: "<library>"})` returns a `depends-on` edge from the consumer carrying the `github:` specifier and `pinned: false`. ([validated by derives and writes graph edges from code imports and package dependencies](../../apps/lore-api/src/work/spec-trace/derive-code-graph.acceptance.test.ts#L21)) ([validated by derives a depends-on edge from a package.json with a github: specifier](../../apps/lore-api/src/work/spec-trace/derive-code-graph.test.ts#L6))
- Statement 2. `lore_query_graph({entity: "<exported symbol>", relation_type: "uses"})` returns the importing files with their repos; an export with no importers returns an explicit derived-and-empty result, distinguishable from not-derived. ([validated by derives and writes graph edges from code imports and package dependencies for used and unused exports](../../apps/lore-api/src/work/spec-trace/derive-code-graph.acceptance.test.ts#L21))
- Statement 3. The `exports` edge set for the library lists each public export of its entry module with kind and source path. ([validated by derives and writes graph edges from code imports and package dependencies](../../apps/lore-api/src/work/spec-trace/derive-code-graph.acceptance.test.ts#L21))
- Statement 4. A per-repo import-set query returns exactly the symbols the consumer imports and shows zero importers for the library's unused modules. ([validated by derives and writes graph edges from code imports and package dependencies](../../apps/lore-api/src/work/spec-trace/derive-code-graph.acceptance.test.ts#L21))
- Statement 5. `lore_query_graph({entity: "<subclass>"})` returns an `extends` edge to its base type with the added member and its source path. ([validated by derives and writes graph edges from code imports and package dependencies](../../apps/lore-api/src/work/spec-trace/derive-code-graph.acceptance.test.ts#L21))
- Statement 6. Re-ingesting an unchanged repo produces an identical edge set: derivation is deterministic and needs no `lore_write_episode`. ([validated by derives and writes graph edges from code imports and package dependencies](../../apps/lore-api/src/work/spec-trace/derive-code-graph.acceptance.test.ts#L21))
- Statement 7. Edges are derived for all onboarded repos, including those where `auto_ingest_graph` is off. ([validated by derives and writes graph edges from code imports and package dependencies](../../apps/lore-api/src/work/spec-trace/derive-code-graph.acceptance.test.ts#L21))
